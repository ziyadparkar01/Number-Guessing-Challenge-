# 🎯 Number Guessing Challenge

A simple and interactive browser-based number guessing game built using **HTML, CSS, and JavaScript**.

The objective of the game is to guess the secret number randomly selected by the computer before running out of attempts. Players can choose different difficulty levels and receive hints after every incorrect guess.

## 🌐 Live Demo

[Play Number Guessing Challenge](https://number-guessing-challenge-rho.vercel.app/)

## 📌 About the Project

Number Guessing Challenge is a beginner-friendly web development project designed to demonstrate the use of HTML, CSS, and JavaScript together.

When the game starts, the computer generates a random number based on the selected difficulty level. The player enters guesses, and the game provides feedback indicating whether the guessed number is too high or too low.

The game also tracks the remaining attempts and calculates the player's score.

## ✨ Features

- **Three Difficulty Levels:** Easy, Medium, and Hard.
- **Random Number Generation:** The computer selects a new secret number for every round.
- **Higher and Lower Hints:** Players receive hints after incorrect guesses.
- **Attempt Tracking:** Displays the number of attempts remaining.
- **Scoring System:** Rewards players for guessing correctly with more attempts remaining.
- **Input Validation:** Prevents invalid entries and numbers outside the selected range.
- **Result Screen:** Displays the final result, correct number, attempts, and score.
- **Play Again:** Allows players to start another round.

## 🎮 Difficulty Levels

| Level | Number Range | Attempts |
|---|---|---|
| Easy | 1–50 | 10 |
| Medium | 1–100 | 7 |
| Hard | 1–200 | 5 |

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Select your preferred difficulty level.
6. Click on Start Game.
7. Enter your guess and click Submit Guess.
8. Use the hints to find the correct number.
